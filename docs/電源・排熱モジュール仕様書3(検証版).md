## 1. 概要

本モジュールは、ミッションシステム（レーザなど）や宇宙船・コロニーの「電力要求」と「排熱要求」を受け取り、指定された環境で必要な発電システム、蓄電池、蓄熱材、ラジエータの規模（面積・容積・質量）を計算する。

排熱の計算では、宇宙空間や月面の真空中での放射冷却だけでなく、火星の薄い大気やタイタンの濃い大気での対流による熱伝達（空冷）と、天体表面の環境温度をまとめて扱う。これにより、環境に合わせた熱・電力の設計を比べられる。

## 2. インターフェース設計（分離境界）

- **前段「ミッション・負荷モジュール」からの入力**：ピーク電力 $P_{peak}$、待機電力 $P_{idle}$、それぞれの時間 $t_{peak}$・$t_{idle}$、ミッション機器の排熱（ピーク時 $Q_{pl,peak}$、待機時 $Q_{pl,idle}$）。
  - 例：レーザ発振・送電モジュールの要求入力電力 $P_{in}$ と要求排熱量 $Q_{waste}$ を、ピーク時の値として受け取る。
- **熱源との境界**：原子炉は、本モジュールでは「熱源」として簡単に扱う（クラスごとのプリセット）。詳しい炉心と遮蔽の計算は「原子炉・遮蔽モジュール」で行う。将来モジュールを連携させるときは、本モジュールが必要な熱出力 $Q_{th}$ と高温側の温度 $T_{hot}$ を原子炉・遮蔽モジュールに渡し、炉と遮蔽の質量を受け取る。
- **後段・UIへの出力**：システムの総質量と内訳、各種面積（太陽電池、集光鏡、ラジエータ）、蓄電池と蓄熱材の容積。

## 3. 入力パラメータ (Input)

内部の値はSI単位で持つ。「表示単位」は画面で選べる単位。プリセットの「区分」は、**検証済み**（文献値・実機の値・計算で裏付けた値）と **参考値**（おおよその目安）の2つ。

- **地球低軌道・火星低軌道の日陰時間**：軌道面に太陽が乗っている最悪の場合の値。天体の陰になる角度（地球：$\arcsin(6371/6771) = 70.2°$）から計算した。
- **$T_{sink}$（軌道上）**：ラジエータの向き（天体の方を向くか、宇宙の方を向くか）で大きく変わる。地球低軌道では150〜260 K 程度。
- **月面（赤道）の $T_{sink}$**：昼に、垂直に立てたラジエータが熱い地面（正午で約390 K）を半分見ている場合の値。夜は100 K以下まで下がる。設計は昼の最悪の場合で行う。
- **月面の極域**は、日照の多い場所（日照率80〜90%）があるが、場所によって条件が大きく違うので、カスタムで入力する。
- **火星表面の $I_\odot$**：大気の外の589 W/m² に、ちり（τ ≈ 0.5）による透過率（約0.6）と、太陽の高さの変化による平均（約0.64）を掛けた、日照中の平均の値。水平に置いたパネルを想定。ちりの付着による劣化は §3.5 の劣化係数で表す。
- **地球表面**：
  - $I_\odot$ は、大気の外の1361 W/m² に、晴天時の大気の透過率（約0.75）と、太陽の高さの変化による平均（約0.5〜0.64）を掛けた、日照中の平均の値。水平に置いたパネルを想定。曇りや季節の変化は含めない。
  - $T_{sink}$ は、晴れた夜空の実効温度（約255〜280 K）と地面（約288 K）を半分ずつ見る垂直のラジエータを想定。$T_{env}$ は地表の平均気温。$h_c$ は弱い風がある場合の空冷。
  - 地上の発電所は、川や海の水や冷却塔で復水器を冷やす。本モジュールが扱うのは空気への放熱（放射と対流）だけで、水による冷却は扱わない。
- **タイタン表面の $I_\odot$**：大気の外で約15 W/m²、地表は厚いもやで約1/10以下になる。地表の太陽光は地球の約1/1000（Huygens 探査機の観測）。太陽光発電は事実上使えない。

### 3.2 負荷パラメータ

| 記号 | 名称 | 内部単位 | 表示単位 | 初期値 | 範囲 |
|---|---|---|---|---|---|
| $P_{peak}$ | ピーク電力 | W | W / kW / MW / GW | 20 kW | 0 以上 |
| $t_{peak}$ | ピークの時間（1サイクルあたり） | s | 秒 / 分 / 時間 | 10 分 | > 0 |
| $P_{idle}$ | 待機電力 | W | W / kW / MW / GW | 5 kW | 0 以上、$P_{peak}$ 以下 |
| $t_{idle}$ | 待機の時間（1サイクルあたり） | s | 秒 / 分 / 時間 | 50 分 | 0 以上 |
| $Q_{pl,peak}$ | ミッション機器の排熱（ピーク時） | W | W / kW / MW / GW | $P_{peak}$ と同じ | 0 以上 |
| $Q_{pl,idle}$ | ミッション機器の排熱（待機時） | W | W / kW / MW / GW | $P_{idle}$ と同じ | 0 以上 |
| $T_{payload}$ | ミッション機器用ラジエータの温度 | K | K / ℃ | 300 K | > 0 |
| `payload_design` | ミッション機器の排熱の設計基準 | Enum | — | ピークで設計 | ピークで設計 / 平均で設計（蓄熱あり） |

- 排熱の初期値を電力と同じにするのは、機器が使った電力は最終的にすべて熱になるため。レーザのように、電力の一部が光として外に出る機器では、ユーザーが値を変える（例：レーザ発振・送電モジュールの $Q_{waste}$）。
- **ピークで設計**：ラジエータがピーク時の排熱をそのまま捨てられる大きさにする。蓄熱は不要。
- **平均で設計**：ラジエータは平均の排熱を捨てられる大きさにする。ピーク時に捨てきれない熱は、蓄熱材にためて、待機中に捨てる。

### 3.3 蓄熱パラメータ（「平均で設計」のときだけ表示）

| 記号 | 名称 | 内部単位 | 表示単位 | 初期値（水） | 区分 |
|---|---|---|---|---|---|
| `ts_medium` | 蓄熱材の種類 | Enum | — | 水（H2O） | 当面は「水」と「カスタム」。将来、種類を追加する |
| $c_{ts}$ | 比熱 | J/(kg·K) | kJ/(kg·K) | 4180 | 検証済み（液体の水） |
| $\Delta T_{ts}$ | 蓄熱材の温度の変化幅（ためる前と後の温度差） | K | K | 10 | 参考値（ミッション機器の温度をどこまで変えてよいかで決まる） |
| $L_{ts}$ | 融解熱（固体と液体の変化を使う場合） | J/kg | kJ/kg | 0 | 水は液体のまま使う前提で0。氷が融ける熱を使う場合は 334 kJ/kg |
| $\rho_{ts}$ | 密度 | kg/m³ | kg/m³ | 1000 | 検証済み（液体の水） |

- 質量あたりの蓄熱量は $e_{ts} = c_{ts}\,\Delta T_{ts} + L_{ts}$。水の初期値では 41.8 kJ/kg。
- どの値も手で変えられる。値を変えると、種類の表示は「カスタム」になる。
- 将来、蓄熱材の種類（パラフィン、溶融塩、レゴリスなど）を選ぶと、これらの値が入るようにする。
- 容器や熱交換器の質量は含めない。

## 4. 内部計算ロジック (Physics Model)

ステファン＝ボルツマン定数 $\sigma = 5.670\times10^{-8}$ W/(m²·K⁴)。

### 4.1 負荷の平均と排熱の設計値

負荷の1サイクルの長さ $T_{load} = t_{peak} + t_{idle}$。

$$P_{avg} = \frac{P_{peak}t_{peak} + P_{idle}t_{idle}}{T_{load}},\qquad Q_{pl,avg} = \frac{Q_{pl,peak}t_{peak} + Q_{pl,idle}t_{idle}}{T_{load}}$$

ミッション機器用ラジエータの設計排熱 $Q_{pl}$ と、必要な蓄熱量 $E_{ts}$：

| 設計基準 | $Q_{pl}$ | $E_{ts}$ |
|---|---|---|
| ピークで設計 | $Q_{pl,peak}$ | 0 |
| 平均で設計 | $Q_{pl,avg}$ | $(Q_{pl,peak} - Q_{pl,avg})\cdot t_{peak}$ |

> 平均で設計する場合、ピーク時に捨てきれない熱 $(Q_{pl,peak} - Q_{pl,avg})t_{peak}$ を蓄熱材にためる。待機中に捨てる熱 $(Q_{pl,avg} - Q_{pl,idle})t_{idle}$ と等しくなるので、1サイクルで収支がつり合う。

### 4.2 必要発電量と蓄電池容量

**(1) 一定の出力を出す電源（原子炉）**

ピーク時に足りない電力は蓄電池から出し、待機中の余った電力で充電する。充電した電力のうち $\eta_{bat}$ の割合だけが取り出せるとすると、収支は次のようになる。

$$(P_{base} - P_{idle})\,t_{idle}\,\eta_{bat} = (P_{peak} - P_{base})\,t_{peak}$$

$$\Rightarrow\ P_{base} = \frac{P_{peak}t_{peak} + \eta_{bat}P_{idle}t_{idle}}{t_{peak} + \eta_{bat}t_{idle}}$$

必要発電量は $P_{gen} = P_{base}$。

**(2) 日照に左右される電源（太陽電池、太陽熱）**

日照の時間 $t_{sun} = T_{cyc} - t_{ecl}$。

日陰の間に必要な電力量 $E_{ecl}$ は、**日陰が負荷のピークの始まりと重なる最悪の場合**で計算する。日陰の時間に負荷のサイクルが $n$ 回入り、余りの時間が $r$ だとする。

$$n = \left\lfloor \frac{t_{ecl}}{T_{load}} \right\rfloor,\quad r = t_{ecl} - nT_{load}$$

$$E_{ecl} = n\,(P_{peak}t_{peak} + P_{idle}t_{idle}) + P_{peak}\min(r, t_{peak}) + P_{idle}\max(0,\ r - t_{peak})$$

日照中に、自分の負荷をまかなう分（$P_{base}$）に加えて、日陰の分を充電する。

$$P_{gen} = P_{base} + \frac{E_{ecl}}{\eta_{bat}\,t_{sun}}$$

**(3) 蓄電池容量**

蓄電池から取り出す電力量は、「日陰を乗り切る量」と「日照中にピークを補う量」の大きいほうとする。

$$E_{shave} = \max(0,\ P_{peak} - P_{gen})\cdot t_{peak}$$

$$C_{bat} = \frac{\max(E_{ecl},\ E_{shave})}{DoD}$$

$$M_{bat} = \frac{C_{bat}}{e_{bat}},\qquad V_{bat} = \frac{C_{bat}}{v_{bat}}$$

> 近似：日照中にピークを補うときの充放電の損失は、(2) の $P_{base}$ にすでに含まれる。日陰の後の充電と、ピークを補ったあとの充電が重なる場合の細かな収支は扱わない。

### 4.3 発電システム

**(a) 太陽電池**

$$A_{pv} = \frac{P_{gen}}{\eta_{pv}\,f_{deg}\,I_\odot},\qquad M_{pv} = A_{pv}\,\rho_{pv}$$

太陽電池が自分で出す熱は、パネル自身から放熱されるものとし、ラジエータには含めない。

**(b)(c) 熱機関（原子炉、太陽熱で共通）**

$$\eta_{carnot} = 1 - \frac{T_{cold}}{T_{hot}},\qquad \eta_{th} = \eta_{mech}\cdot\eta_{carnot}$$

$$Q_{th} = \frac{P_{gen}}{\eta_{th}},\qquad Q_{rej} = Q_{th} - P_{gen}$$

$$M_{conv} = \alpha_{conv}\cdot P_{gen}$$

**原子炉の場合**

$$M_{reactor} = \alpha_r\cdot Q_{th},\qquad M_{shield} = \begin{cases}\alpha_s\cdot Q_{th} & (\text{含める})\\ 0 & (\text{含めない})\end{cases}$$

**太陽熱の場合**

$$A_{conc} = \frac{Q_{th}}{\eta_{conc}\,I_\odot},\qquad M_{conc} = A_{conc}\,\rho_{conc}$$

### 4.4 蓄熱材

$$e_{ts} = c_{ts}\,\Delta T_{ts} + L_{ts},\qquad M_{ts} = \frac{E_{ts}}{e_{ts}},\qquad V_{ts} = \frac{M_{ts}}{\rho_{ts}}$$

### 4.5 ラジエータ（放射＋対流）

パネルの面積（片面）1 m² あたりの放熱量：

$$q(T) = n_{side}\,\eta_{fin}\left[\epsilon\sigma\left(T^4 - T_{sink}^4\right) + h_c\left(T - T_{env}\right)\right]$$

- 1項目が放射、2項目が対流。大気がない場所では $h_c = 0$。
- それぞれの寄与 $q_{rad}$、$q_{conv}$ も出力する。

熱機関用とミッション機器用の面積：

$$A_{rad,eng} = \frac{Q_{rej}}{q(T_{cold})},\qquad A_{rad,pl} = \frac{Q_{pl}}{q(T_{payload})}$$

$$M_{rad} = (A_{rad,eng} + A_{rad,pl})\cdot\rho_{rad}$$

- 熱機関用ラジエータの温度は、熱機関の低温側の温度 $T_{cold}$ と同じとする（熱交換器での温度の低下は無視する）。

### 4.6 総質量

$$M_{gen} = \begin{cases} M_{pv} & (\text{太陽電池})\\ M_{reactor} + M_{shield} + M_{conv} & (\text{原子炉})\\ M_{conc} + M_{conv} & (\text{太陽熱})\end{cases}$$

$$M_{total} = M_{gen} + M_{bat} + M_{ts} + M_{rad}$$

**グラフの使い方の例**
- X軸：$T_{cold}$、Y軸：$M_{total}$。低温側の温度を上げると、熱効率が下がって熱出力（原子炉の質量）が増える。一方で、ラジエータは急に小さくなる（温度の4乗で効く）。総質量が最小になる温度がある。
- X軸：$h_c$、Y軸：ラジエータ総面積。火星表面で、ファンで強制空冷する効果が分かる。
- X軸：$t_{ecl}$、Y軸：$M_{bat}$。月面の夜の長さが蓄電池にどれだけ効くかが分かる。

## 6. 入力チェック（エラー・警告）

| 種類 | 条件 | メッセージ（案） |
|---|---|---|
| エラー | $q(T_{payload}) \le 0$ または $q(T_{cold}) \le 0$ | この温度では、環境へ熱を捨てられません（ヒートポンプなどの能動冷却が必要です） |
| エラー | $T_{cold} \ge T_{hot}$ | 低温側の温度は、高温側の温度より低くしてください |
| エラー | 太陽電池・太陽熱で $I_\odot \le 0$、または $t_{ecl} \ge T_{cyc}$ | 日照がないため、太陽光では発電できません |
| エラー | $P_{idle} > P_{peak}$ | 待機電力はピーク電力以下にしてください |
| エラー | $\eta_{bat}$、$DoD$、$\eta_{pv}$、$\eta_{mech}$、$\eta_{conc}$、$\eta_{fin}$ が 0 以下または 1 より大きい | 0 より大きく 1 以下で入力してください |
| 警告 | 放射の項がマイナス（$T < T_{sink}$）、または対流の項がマイナス（$T < T_{env}$） | 放射（または対流）では、ラジエータが逆に熱を受け取っています |
| 警告 | 太陽電池で $I_\odot < 10$ W/m² | 日射が非常に弱いため、太陽電池が非常に大きくなります |
| 警告 | 蓄熱材が水で、$T_{payload}$ が 273 K 未満または 373 K を超える | 1気圧では水が液体でいられない温度です（凍結するか沸騰します）。加圧や別の蓄熱材を検討してください |
| 情報 | 炉のクラスで遮蔽が「未設定」なのに「含める」を選んだ | このクラスの遮蔽の比質量は未設定です。原子炉・遮蔽モジュールで扱う予定です |
| 情報 | 地球低軌道などで、1周期より負荷サイクルが短く、$DoD > 0.4$ | 充放電の回数が多い場合、電池の寿命のため放電深度を下げるのが普通です |

## 7. 特記事項・制約

- **大気冷却の効果**：対流熱伝達率 $h_c$ を入れることで、「火星表面でファンを回して強制空冷する（その分の質量や電力が増える）代わりに、ラジエータの面積を大きく減らす」といったトレードオフをシミュレートできる。タイタンのような極低温で濃い大気では対流が支配的になり、排熱の設計が非常に容易になる（T5：放熱の91%が対流）。
- **排熱の限界**：放射と対流を合わせた放熱量がゼロ以下になる温度では、自然には排熱できない。この場合はエラーを出す。ヒートポンプなどの能動冷却は計算しない。
- **計算に含めないもの**：
  - 原子炉の遮蔽の詳しい計算（原子炉・遮蔽モジュールで扱う）
  - ヒートポンプによる能動冷却
  - 電力変換回路の損失、蓄電池の損失による発熱
  - 熱交換器での温度の低下
  - 太陽熱の蓄熱による日陰中の発電
  - ラジエータの両面が天体や機体を見ることによる放熱の低下（$T_{sink}$ にまとめて含める）
  - 強制空冷のファンの質量と電力

## 8. 拡張への備え

- **熱源と熱機関を分ける**：熱源（原子炉、太陽熱、将来の核融合）は「熱出力 $Q_{th}$ と高温側の温度 $T_{hot}$、熱源の質量」を返す部品とし、熱機関（§4.3）と組み合わせる。核融合を追加するときは、熱源を1つ追加するだけで済むようにする。
- **直接発電**：核融合で検討されている直接発電（熱機関を通さずに電力を取り出す方式）は、「熱機関を通さない発電方式」として、発電量・排熱とその温度・質量を返す形で追加できるようにする。
- **蓄熱材の種類**：§3.3 の2つの値を、蓄熱材の種類のプリセットとして選べるようにする。
- **原子炉・遮蔽モジュールとの連携**：本モジュールの $Q_{th}$ と $T_{hot}$ を原子炉・遮蔽モジュールに渡し、$M_{reactor} + M_{shield}$ を受け取る。
